# FileDedup — File Deduplication Dashboard

A file deduplication system designed to identify duplicate files, display scan results through a web dashboard, and support safer file management through quarantine and restoration.

## 📌 Project Overview

FileDedup helps users identify duplicate files within a selected directory. It uses a C-based scanning program and SHA-256 hashing to identify files with matching content. A Python backend connects the scanner to a web-based dashboard built using HTML, CSS, and JavaScript.

The dashboard is intended to make duplicate-file analysis easier through organized results, file details, and visual summaries.

## 🎯 Objectives

- Identify duplicate files in a selected directory.
- Compare file content using SHA-256 hashes.
- Display duplicate groups and file information.
- Provide a simple and user-friendly web interface.
- Support reviewing selected files before quarantine.
- Provide a restoration workflow for quarantined files.
- Help users understand duplicate-file storage and management.

## ✨ Features

- **Duplicate Detection:** Identifies files with matching content hashes.
- **Web Dashboard:** Presents scan results in a browser-based interface.
- **File Details:** Helps users review duplicate files and their locations.
- **Visual Analytics:** Intended to summarize scan results using dashboard statistics and charts.
- **Selective Quarantine:** Designed to let users select copies for quarantine rather than permanently deleting them immediately.
- **Restore Support:** Designed to support restoring quarantined files.
- **Modular Architecture:** Separates scanning, server-side processing, and the user interface.

*Note: The availability and correct operation of each feature depend on the installed implementation and should be tested before presenting them as verified.*

## 🚀 Installation and Execution

### 1. Download or clone the project

If you download the repository as a ZIP from GitHub, extract it and open the extracted project directory in Ubuntu.

Move into the project directory:

```bash
cd ~/filededup
```

### 2. Compile the C scanner

```bash
gcc -Wall -Wextra -O2 backend/main.c -o backend/filededup -lcrypto
```

This command compiles the C source code and links the OpenSSL crypto library.

### 3. Start the backend server

```bash
python3 backend/server.py
```

Keep the terminal open while the server is running.

### 4. Open the dashboard

Open the following address in your browser:

```text
http://127.0.0.1:8088
```

If the server reports a different address or port, use the address printed in the terminal.

The directory contains two files with identical content and one file with different content.

Use the dashboard's folder selection or scan input to scan:

```text
/home/bhaar/FileDedup_Demo
```

Check whether the dashboard identifies `report.txt` and `report_copy.txt` as duplicates.

## 🔍 How It Works

1. The user selects a directory to scan.
2. The C scanner examines the files.
3. The scanner computes SHA-256 hashes to identify matching content.
4. The backend makes the scan results available to the dashboard.
5. The frontend displays duplicate groups and related file information.
6. The user reviews the results before taking any cleanup action.

## 🔐 Safe File Management

Duplicate detection and file deletion are different operations. FileDedup is designed to support a review-first workflow.

- Inspect file names, paths, and duplicate groups before taking action.
- Test quarantine and restoration with sample files first.
- Verify that the correct file is selected and that the original copy remains available.
- Keep backups of important data.
- Do not treat a matching hash alone as permission to delete a file.
