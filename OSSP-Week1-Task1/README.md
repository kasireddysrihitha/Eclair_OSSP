# OSSP Week 1 Task 1

## Task
Develop a C program that demonstrates process creation in Linux using the fork() system call.

## Description
This program creates a child process using fork(). It displays the process IDs of the child and parent processes and uses execlp() to execute the Linux command entered by the user.

## Technologies Used
- C
- Linux
- fork()
- execlp()

## How to Compile
gcc process.c -o process

## How to Run
./process
